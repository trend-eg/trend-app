# Trend Agency App · تطبيق ترند

تطبيق ويب (PWA) لوكالة ترند للدعاية والإعلان: الأعمال والعملاء، الفيديوهات، الخدمات، فحص مجاني للحضور الرقمي، وطلب عرض سعر على واتساب.

## التشغيل على GitHub Pages
1. Settings › Pages
2. Source: **Deploy from a branch** · Branch: **main** · Folder: **/ (root)** › Save
3. بعد دقيقة أو اتنين هيشتغل على: `https://<username>.github.io/<repo>/`

## الملفات
- `index.html` — التطبيق كله (HTML + CSS + JS)
- `privacy.html` — سياسة الخصوصية (عربي / English)
- `manifest.webmanifest`, `sw.js` — التثبيت على الموبايل والتشغيل بدون نت
- `img/` لوجوهات العملاء والأيقونات · `thumbs/` صور الفيديوهات المصغرة · `featured/` الفيديوهات المميزة
- `HANDOFF.md` — ملخص المشروع واللي لسه مطلوب
